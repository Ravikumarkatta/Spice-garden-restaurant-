# Spice Garden - Italian Restaurant Website

A modern, responsive single-page website for Spice Garden, a fictional Italian restaurant.

## Features

- Fully responsive design (mobile-first approach)
- Interactive menu with category filtering
- Testimonial slider
- Contact form with frontend validation
- Smooth scrolling navigation
- Sticky header
- Back-to-top button
- Animated elements

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6)
- Font Awesome icons
- Google Fonts

## Installation

No installation required. Simply open `index.html` in your browser.

## Deployment

This project can be deployed to any static hosting service like:
- GitHub Pages
- Netlify
- Vercel

## Future Enhancements

- Add a reservation system
- Implement a dark mode toggle
- Add more animations
- Connect to a backend for form submissions
- Add a real-time menu feature
